# Meta Intel Technologies — Field Operations & Retail Execution Platform

Web application for a TTL marketing agency.

## Stack
React + TypeScript + Vite + Tailwind + Supabase

## Setup
1. npm install
2. Copy .env.example to .env, fill in Supabase values
3. Run migrations in supabase/migrations/ in the Supabase SQL Editor
4. Insert a profile row for your user with role SUPER_ADMIN
5. npm run dev
