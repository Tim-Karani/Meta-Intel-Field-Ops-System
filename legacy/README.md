# Legacy visual template

The original React + Supabase prototype that was supplied as a **visual template only**. It is kept here for design
reference and is **not part of the running system** — the production web application is in `../web` (vanilla
HTML/CSS/JS) and talks to the Laravel API in `../backend`, as specified in `docs/`.

Nothing in this folder is built, tested or deployed by the CI workflow or Docker setup.
